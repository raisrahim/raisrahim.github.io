### Close-source

#### *Connexing.io (2022 – 2024)*
* AI-powered talent marketplace using Spring Cloud and Event-Driven Architecture (EDA) powered by Apache Kafka for high-throughput event processing.

#### *PT Bank Muamalat Indonesia (2018 – 2021)*
- Microservices backend for the flagship mobile banking platform (Muamalat DIN).
- [Internet Banking for individual](https://ib.muamalatbank.com/ib-app) and [Corporate Cash Management Systems (CMS)](https://cms.bankmuamalat.co.id/cms-app), focusing on secure remittance workflows and institutional banking features.
- Delivered national payment rail and regulatory integrations, including SKN/RTGS clearing transfers, Ministry of Finance Sukuk investment services, PLN, and Dukcapil.
- Built the modern web-based Branch Delivery System to streamline teller operations and enhance transaction security.

#### *PT Tokio Marine Life Insurance Indonesia (2016 – 2017)*
- Led modernization from monolithic architectures to Linux-hosted microservices centered around a unified API Gateway.
- Engineered a multi-threaded batch digital E-Policy distribution system using JavaEE (Wildfly Swarm) integrated with SendGrid and NeverBounce.
- Designed a microservices integration layer for broker and bancassurance channels (Futuready) to automate high-volume insurance policy submissions and underwriting approvals.
- Built a configuration-driven cross-channel Sales Illustration engine using JavaFX and automated compensation data processing pipelines using T-SQL stored procedures.

#### *PT Xybase Indonesia (2014 – 2016)*
- Modernized the core airport management suite using Spring Boot, Apache Camel, and MarkLogic, delivering WebSocket dashboards and JSON streaming engines for flight milestone tracking.
- Developed flight data synchronization services for Boston Logan International Airport (USA) integrating SOAP feeds via Dropwizard and JMS.
- Implemented a real-time Airport Resource Management System (RMS) with interactive Gantt scheduling for gate, stand, and staff allocations at Kazan International Airport (Russia).

#### *PT PrismaLink International (2011 – 2014)*
- Maintained and enhanced high-availability Internet Banking engines and multi-service payment gateways using Spring, Hibernate, and JBPM workflows for Bank Nusantara Parahyangan.
- Managed database migrations and performance optimizations from Oracle to PostgreSQL.

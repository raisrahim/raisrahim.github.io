## Enterprise Systems (Closed-Source)

### ALAMI Sharia / Hijra Group (2021 – 2024)
- Developed a dynamic Risk Acceptance Criteria (RAC) evaluation engine using Spring Expression Language (SpEL) for real-time financing pre-screening.
- Led enterprise integrations with regulatory and credit institutions, including Pefindo (Credit Bureau), OJK, and fintech data centers.

### Connexing.io (2022 – 2024)
- Engineered backend microservices for an AI-powered talent marketplace to facilitate automated role-matching for enterprise clients.
- Implemented Event-Driven Architecture (EDA) using Spring Cloud and Apache Kafka for high-throughput streaming and resilient cross-timezone data distribution.

### PT Bank Muamalat Indonesia (2018 – 2021)
- Orchestrated the architectural transition to high-concurrency microservices for the flagship mobile banking platform ([Muamalat DIN](https://www.bankmuamalat.co.id/)).
- Directed development for [Retail Internet Banking](https://ib.muamalatbank.com/ib-app) and [Corporate Cash Management Systems (CMS)](https://cms.bankmuamalat.co.id/cms-app), prioritizing institutional remittance workflows and security hardening.
- Delivered national payment rail and statutory integrations, including SKN/RTGS national clearing modules, Ministry of Finance Sukuk investments, PLN, and Dukcapil.
- Built the web-based Branch Delivery System to streamline branch teller workflows and enhance transaction security.

### PT Tokio Marine Life Insurance Indonesia (2016 – 2017)
- Led modernization from monolithic architectures to Linux-hosted microservices centered around a unified API Gateway.
- Engineered a multi-threaded batch digital E-Policy distribution system using JavaEE (Wildfly Swarm) integrated with SendGrid and NeverBounce.
- Designed a microservices integration layer for broker and bancassurance channels ([Futuready](http://futuready.com)) to automate high-volume policy submissions and underwriting approvals.
- Developed a configuration-driven cross-channel Sales Illustration tool in JavaFX and automated tax/compensation calculations using high-performance T-SQL stored procedures.

### PT Xybase Indonesia (2014 – 2016)
- Modernized the airport management suite using Spring Boot, Apache Camel, and MarkLogic, delivering WebSocket dashboards and high-speed JSON streaming engines for flight milestone tracking.
- Engineered a data synchronization engine for Boston Logan International Airport (USA) integrating real-time SOAP flight feeds via Dropwizard and JMS.
- Implemented a real-time Airport Resource Management System (RMS) with interactive Gantt scheduling for gate, stand, and staff allocations at Kazan International Airport (Russia).

### PT PrismaLink International (2011 – 2014)
- Maintained and enhanced 24/7 Internet Banking engines and multi-service payment gateways using Spring, Hibernate, and JBPM workflows for Bank Nusantara Parahyangan.
- Managed database migrations and query optimization from Oracle to PostgreSQL.
